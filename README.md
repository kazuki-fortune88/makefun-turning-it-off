A make.fun one-liner bounty entry. `main.py` writes a single line of tech-support dialogue to `entry.txt` — a cheerful, useless support agent's reply to a desperate customer, twisting the classic "turn it off and on again" cliche.

## The line

> Have you tried turning it off and on again? Great — now do it slower, so I can pretend there's a step two.

## Run

```sh
python3 main.py
```

This writes the line to `entry.txt` in `$MAKEFUN_OUTPUT_DIR` (or `/output` if unset).
